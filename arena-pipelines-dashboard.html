📖 How to Use

What is this?

A single-page dashboard that aggregates GitLab pipelines from multiple projects into one view. No more clicking through every project in GitLab to see pipeline health.

Quick start

  • Click ⚙ Settings in the top right.
  • Enter your GitLab Base URL (e.g. https://gitlab.digi.internal).
  • Enter a Personal Access Token with api scope.
  • The project list is pre-filled with all Arena services. Click Save & Load.

Tabs

  • Pipelines — live table of all pipelines with status, branch, duration, and expandable jobs.
  • Rerun — trigger a new pipeline for any project. Select an existing branch or type a custom one.

Features

  • Filter by status (Running / Failed / Success / …) and search by project or branch.
  • Sort by any column (click the header).
  • Auto-refresh every 30 seconds (toggle next to Refresh).
  • Jobs panel shows stage breakdown, per-job status, and a progress bar. Allowed-to-fail jobs (e.g. SonarQube) show as warning instead of failed.

Token & security

Your settings (URL, token, and project list) are saved in localStorage so they persist after page refresh. The token is only used in direct browser API calls to GitLab — it is never sent to any other server.

Troubleshooting

  • CORS error — If you get CORS blocked, ensure your self-managed GitLab allows cross-origin requests with the PRIVATE-TOKEN header.
  • 404 / 403 — Check that your token has api scope and that you have access to the listed projects.
